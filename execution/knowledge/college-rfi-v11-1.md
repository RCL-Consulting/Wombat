## Why you are receiving this

Wombat implements the Paediatric EPA framework v11.1 as a working assessment system. The
catalogue is loaded and running against test data: all **15 EPAs**, the six entrustment
levels (1, 2, 3a, 3b, 4, 5), the per-EPA annual frequencies, and Annexure A's table of which
assessment tools are permitted on which EPA.

Annexure A names **fourteen** assessment instruments. **Four** are built — CBD, Mini-CEX,
DOPS and Direct observation. The remaining ten cannot be built responsibly without decisions
that are not in the document and that only the College can make.

This message collects all of them. It is one batch rather than fourteen emails because they
interlock, and because each one is an ask of clinicians' time.

## How to reply

**Most questions carry a proposed default.** Where the default is right, you need do nothing
but say so. A reply of *"defaults confirmed except D9 and D13, see below"* is a complete
answer and is the fastest path.

**Four questions have no safe default** and are marked **⚑ needs an explicit answer**. If
nothing else comes back, these four are the ones that matter: **D1, D12, D13, D16.**

The `D-` numbers are our internal tracking references. Quoting them in a reply lets us match
each answer to the work it releases.

## A. The one that gates the rest

### ⚑ D1 — Is v11.1 final, or is the "DRAFT — FOR DISCUSSION" cover current?

The cover page of the v11.1 document states that the content is subject to revision. We have
been told the framework is finalised. These cannot both be true, and the difference matters:
the catalogue is held nationally and adopted by institutions, so publishing it is a national
act rather than a local configuration choice.

It also gates this entire message. Commissioning ten assessment form designs from busy
clinicians against a draft is not a reasonable ask.

**Options** — (a) treat v11.1 as final and build against it; (b) hold the ten remaining tools
until a final version is issued; (c) build now and re-version the catalogue when v11.2 lands.

**No default proposed.** Please answer this one first, even if the rest take longer.

## B. The instruments

### D4 — Is "Case note review" a distinct instrument, or another name for CCA?

Annexure A lists **Case note review** on EPA 6 only, with no descriptive prose anywhere in the
document. **CCA (Clinical Case Analysis)** appears on EPAs 1, 2, 3 and 4, and page 8 defines it
as *"review of clinical documentation and discussion of the reasoning and management plan
recorded"* — which is a fair description of a case note review.

For reference, EPA 6's full tool list reads: *Direct observation, Mini-CEX, DOPS, Case note
review, MSF (5)*.

**Options** — (a) a distinct instrument needing its own form; (b) the same instrument as CCA,
named differently on EPA 6.
 Answer (b)

**Proposed default: (b), an alias of CCA.** This is one fewer form to design, and one fewer
near-identical entry in a list clinicians have to choose from. If they are genuinely
different, we need to know what a case note review captures that a CCA does not.

### ⚑ D12 — Should the fourteen tool names be treated as fourteen distinct instruments?

Annexure A contains two pairs that may or may not denote the same thing:

| Tool name as published | EPAs naming it |
|---|---|
| **Direct observation** | 2, 4, 6, 9, 10, 11, 13, 15 |
| **Directly observed clinical examination** | 7 only |
| **CCA** | 1, 2, 3, 4 |
| **Case note review** | 6 only (see D4) |

**The consequence, stated plainly.** EPA 7's tool list reads *Mini-CEX, DOPS, Directly observed
clinical examination, MSF (4)* — it does **not** include "Direct observation". If we implement
the table as published, a supervisor who completes a direct observation on EPA 7 will have it
refused, while the same form is accepted on EPA 6. That may be exactly what the College
intends — EPA 7 concerns health promotion and may warrant a specifically examination-shaped
instrument — or it may be an artefact of a document written by several hands.

**Proposed approach: implement all fourteen verbatim, and ask the College to merge any pair
explicitly.** We are reluctant to collapse them on our own judgement: a merge Wombat invents
is invisible and cannot be audited, whereas a merge the College makes is recorded and can be
checked against the published annexure line by line.

**What we need: confirmation that EPA 7 is meant to exclude general direct observation** — or
an instruction to treat the two names as one instrument.

Answer: mini CEX and a clinical examination is the same thing. Would propose: clinical observed interaction 
This will include a mini cex, handover, communication etc.

### D6 — Which instruments produce an entrustment level, and which are evidence only?

Some tools end in a supervisor stating a level on the entrustment ladder. Others are better
understood as evidence that an activity happened, without a rating attached. The distinction
decides whether each instrument can, by itself, move a trainee's entrustment level for an EPA.

**Proposed default:**

- **Rated** (a named assessor states a level): CBD, Mini-CEX, DOPS, Direct observation, CCA,
  RCA (Random Case Analysis), Chart-stimulated recall, Case note review, Directly observed
  clinical examination.
- **Unrated evidence** (recorded, but asserts no level): Reflective exercise, Clinical audit,
  Portfolio and logbook review.
- **MSF** — see section C.

Answer :  default all rated

### D7 — Does an unrated instrument count toward an EPA's annual frequency?

If a trainee's EPA 1 target is eight encounters a year, does a reflective exercise consume one
of the eight?

**Options** — (a) counts toward the number of encounters, but never toward the supervision
level; (b) does not count at all, and is documentation rather than assessment; (c) counts
toward both.

**Proposed default: (a), volume only.** We flag it because it changes what "55 encounters a
year" means. If the 55 is meant to be 55 *supervised, rated* encounters, the answer is (b).

## C. Multi-source feedback

MSF is the most-required instrument in the framework and currently the least well specified.
It is named on more EPAs than any other tool, and it is the one instrument the system cannot
yet credit against any EPA at all.

### D37 — Is MSF specified on eleven EPAs, or on fifteen?

The document says both. Annexure A lists MSF in the tool cell of **15 of 15** EPAs. Annexure
B's prose states that *"Multi-source feedback is specified in eleven of the fifteen EPAs."*
Same document, same version.

This does not change any recommendation below, but it does change the arithmetic in D9.

**One line in reply is enough: eleven or fifteen, and if eleven, which four are excluded.**
Fifteen

### D9 — Is MSF run once per period across many EPAs, or separately per EPA?

This is the question with the largest workload consequence in this message, so the arithmetic
is worth setting out.

Our system requires a minimum of **8 returned questionnaires** before an MSF can be released.

- **Per EPA:** 15 EPAs × 8 responses = **120 questionnaires per registrar per year**. In a
  20-registrar department that places roughly 80 questionnaires a year on each consultant and
  senior nurse. Response rates will collapse and few campaigns will ever complete. (On the
  eleven-EPA reading, 88 per registrar — the same problem.)
- **Per period, covering many EPAs at once:** about **16 per registrar per year**, and about
  16 per respondent.

**Proposed default: one campaign per period, covering multiple EPAs.** We raise it rather than
assume it because it changes what a statement like "MSF completed for EPA 7" means on a record
of progress.
Answer: Proposed default

### D10 — Who states the entrustment level that an MSF asserts, if anyone?

MSF produces averaged scores across respondents. An average of 3.4 is not a point on a ladder
reading 1, 2, 3a, 3b, 4, 5, so something has to translate — or nothing should.

**Options** — (a) the **respondents**, via a direct entrustment question (but respondents
include nurses, allied health professionals and families, who are not all positioned to judge
supervision level); (b) the **releasing reviewer**, who records one level alongside the summary
they already write, as a named clinician standing behind it; (c) **nobody** — MSF contributes
evidence and narrative, and asserts no level.

**Proposed default: (b), the releasing reviewer, with (c) as an acceptable alternative.** Only
option (a) needs a redesign of the questionnaire, so it is the one we would need told.

Anwer: Propsed default
### D8 — Does MSF count toward the 55 encounters a year?

Annexure A's per-EPA frequencies sum to exactly 55, so the 55 appears to *be* the sum of the
per-EPA quotas. If one MSF credits an encounter against every EPA it covers, then two campaigns
a year supply a substantial fraction of the annual total from two questionnaires — and for the
EPAs whose frequency is one per annum, a single MSF would discharge the year.

**Options** — (a) yes, uncapped; (b) yes, capped at one per period per EPA; (c) no — MSF is
required evidence tracked in its own right and does not consume the encounter count.

**Proposed default: (c) for now, moving to (b) once per-period tracking is built.** This keeps
the 55 meaning what the College says it means.

Answer: not sure. 
### D11 — Must a campaign draw responses from more than one respondent group to count?

Our reports suppress any respondent category with too few responses, to protect anonymity. As
built, a campaign answered entirely by eight peer doctors passes the release threshold and
would count as multi-source feedback, with every other category suppressed.

**Proposed default: require that at least two respondent categories survive suppression**
before an MSF counts — on the reasoning that "multi-source" is the point. Please confirm, and
tell us the minimum number of categories if it is not two.

Answer: Proposed default

## D. The annual quota and the academic year

### ⚑ D13 — When does the academic year start, and where does the semester boundary fall?

Annexure B describes roughly five encounters a month across an **eleven-month academic year**,
with 25 of the 55 falling in each semester. It does not say which eleven months, or where the
boundary between semesters sits.

This cannot be derived from the document, and every "how is this registrar doing this
semester?" view depends on it.

**Also: should the boundary be national, or set per institution?** We propose **national** — a
shared boundary is what makes the semester comparison meaningful, and a per-institution
boundary would give two registrars in the same national programme different targets in the
same month.

**No default proposed for the dates themselves.** We need the months.

### D14 — What happens to a registrar who starts mid-year?

They will not have eleven months before the first boundary.

**Options** — (a) pro-rata the target; (b) exempt the partial period and start counting at the
next boundary; (c) carry the shortfall forward.

**Proposed default: (b), exempt the partial period,** stated plainly on the trainee's progress
page. Pro-rata would invent a fraction the College never published. This is a College rule
rather than a software one, so we would rather be told.
 Answer: default
### D15 — Is there a deadline for submitting an assessment after the encounter?

Nothing in the document bounds how long after an encounter an assessment may be filed.

**Proposed default: a soft warning beyond 90 days, and no hard refusal.** We advise against a
hard limit unless the College wants one: a registrar blocked by a date validator will enter
today's date instead, which destroys the accuracy of the encounter date — the very thing the
rule was meant to protect.
Answer: no default time

## E. The descriptors

### ⚑ D16 — Are the 78 descriptors individually assessable, or are they narrative scope?

Each EPA carries descriptors setting out the knowledge and skills it covers. We currently hold
them as descriptive text attached to the EPA — visible to trainees and supervisors, but not
separately tracked.

**Options** — (a) **narrative** — they describe the EPA's scope, and entrustment is judged on
the EPA as a whole; (b) **individually assessable** — each descriptor is signed off in its own
right and contributes to the EPA.

**Proposed default: (a), narrative.** We flag this as one of the four that genuinely needs an
answer because option (b) is a substantially larger piece of work than anything else in this
message, and it would need to be planned before other work is built on top of it. If the
College's intent is (b), we would rather know now than discover it later.

Answers: (a) default
