How the token leaves the address bar (T315) PROPOSED

1. GET /account/register?token=… checks the token, writes it to a short-lived cookie (HttpOnly, Secure, SameSite=Strict, Path=/account/register, 30 minutes) and answers 303 to /account/register.

2. /account/register reads the invitation from the cookie; the submit posts with it; registering, or any refused-link page, deletes it.

3. No script: it works with script blocked, where only the Show toggles are hidden (wombat.js draws them). The token is never in the page, the address or the Referer.

4. A refused password brings back the first and last names from the post, never a password, never the names in the address (T317).
