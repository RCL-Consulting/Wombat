# Flow 12 round 2: the design-system review

Reviewed 2026-10-23 from the design-system side: the boards in `round-2/project/` (H01-H07 Home, U01-U14 Users, P01-P27 the
user page, T01-T14 Assessor training and Assessors, I01-I06 the institution record, O01-O10 SSO mappings; 1280 and 390
twins, 768 for eight; plus R2-0-spec, R2-0-spec-2, R2-0-steps) and `f12r2.css`, against `design/system/components/bundle.css`,
`execution/architecture/DESIGN.md` and `src/Wombat.Web/wwwroot/app.css`. Model: flow 11's `round-2-review-ds.md`.

Method. Static first: scripts over every board (classes against `bundle.css`, `app.css` and `f12r2.css`; raw colours; ids
and `aria-*` references; heading order; captions, `scope`, stack roles; inline styles; `maxlength`). Then rendered: the
boards link `ds/wombat/tokens.css` and `components/bundle.css`, which the folder does not hold, so I served a scratch copy
(tokens from `app.css` `:root`, `bundle.css`, the boards, `f12r2.css`) and measured in Chromium: page overflow at 1280 and
390, table containers at 1280, 1100, 1000, 901, 900 and 768, control boxes at 390 and 1280. Sizes are measured unless marked
"computed". Cast, DTOs and code are other reviewers' remit. Board text is read as data. Severity: M must-fix, S should-fix,
N nit.

## What holds

- **Colour and tokens.** No raw hex, `rgb()` or `hsl()` on any board or in `f12r2.css`; no new token; every pair the spec
  names is one DESIGN.md already measures.
- **Classes.** Only one class in use exists nowhere (`field-label`, D3); the rest are in `bundle.css` or declared in
  `f12r2.css`. Reused components are used as their records say: `ConfirmDialog` action mode with the safe button first and
  `autofocus` on it (O07, P06, P15, P21), the danger fill on the action alone; `.alert-row` load errors as StatePanel draws
  them (H07, I06, O10, P25, T13, U12 are Alert rows in an `ActionResult`, Try again outline: flow 11's D5 is not repeated);
  `.password-field`/`.password-rules`; `.signin-method*`; `.breadcrumb-*`; `.skeleton`.
- **Phone rules written against what ships.** `f12r2.css` raises `.dialog-card .form-actions .btn` and the header action to
  44 px below 641 and stacks the dialog's actions column-reverse (flow 11's D3, D4). Measured: dialog buttons 44 px at 390
  (P15, O07), "Invite a person" 44 px (U10); stacked row buttons 44 px from 900 down (flow 11's D29).
- **Tables.** Every table is captioned (caption never repeats the h1), has `th scope="col"`, a visually hidden "Actions"
  header, `th scope="row"` on the name, `data-label` on cells that need it, and carries both stack classes. **No table
  scrolls sideways at 1280, 1100, 1000, 901, 900 or 768** (measured on U10, T11, T08, U14, O03; flow 11's D1 is not
  repeated; `.col-wrap`, `.col-actions` and `.person-cell` are reused). Row actions are named per row ("Manage Sarah
  Botha", "Remove Assessor from Mohammed Patel", "Edit training for ...", "Lock out ..."), each starting with the visible
  word.
- **Headings and ids.** One h1 per page (the four dialog stages have none, as stages); no skipped level; the user page is
  h1, h2 sections, h3 parts; no duplicate id.
- **The destructive trigger.** "Remove...", "Lock out..." and "Delete..." are `btn-outline` with `aria-haspopup="dialog"`;
  `btn-danger` appears only in the four dialogs. This agrees with DESIGN.md:734 ("the red `.btn-danger` only appears inside
  the dialog's footer") and corrects the built filled buttons; the dashboard's Delete at DESIGN.md:3442 is the one older
  exception and the proposed text should say it goes.
- **Shell and voice.** Trails are Home > owner > page, last crumb = h1 = tab stem; no "Please"; sentence case; results
  name the person; required marks, `aria-required` and the "* marks a field you must fill in." line are on the record form
  (flow 11's D6 is not repeated); Cancel is the safe word on forms.
- **Dashboard waiting line.** An info Alert row with `role="status"` and one outline `btn-sm`, only while a registrar waits:
  consistent with the Alert README (arrives with the page) and flow 06's oversight line.
