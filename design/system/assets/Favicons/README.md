# Favicons

The browser and OS icons `Components/App.razor` and `site.webmanifest` link, copied from `src/Wombat.Web/wwwroot/`. The page's `theme-color` and the manifest's colours are #2c3e50, the value of `primary-color`.

- `favicon.svg`: the tab icon. It is an older drawing than `wombat-mark.svg`, with eyes, blue inner ears, a triangle nose and a faint arc over the burrow, where the current mark has a cross for a nose. Redraw it from the mark when the brand is next touched.
- `apple-touch-icon.png` (180px), `icon-192.png` and `icon-512.png` (`purpose: any maskable`): rendered from `wombat-tile.svg`.
- `favicon.ico` (16, 32 and 48px) is not carried: the store takes no .ico.
