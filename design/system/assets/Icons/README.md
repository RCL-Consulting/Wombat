# Icons

Wombat's 54 Lucide icons (MIT), copied from `src/Wombat.Web/wwwroot/icons/`. Each file is a 24-unit `<svg id="i">` holding bare paths with no stroke or fill attributes: app.css's `.icon` class draws them (fill none, stroke `currentColor`, stroke-width 2, round caps and joins) when `Icon.razor` references one with `<use href="/icons/{name}.svg#i">`. So a tile shown here as a plain `<img>` renders its paths filled black, which is not how the app draws it; the Icon component's preview shows them as drawn. Their ink is the text colour around them.

Named by a page (49): alert-triangle, arrow-left, arrow-left-right, award, ban, book, book-check, book-open, building, calendar, calendar-check, check, chevron-left, chevron-right, circle-plus, clipboard-list, clock, download, file-text, gauge, graduation-cap, history, home, inbox, info, key, list, list-checks, lock, log-in, log-out, mail, menu, message-square, plus, refresh-cw, scale, search, settings, shield-check, stethoscope, trending-up, triangle-alert, user, user-check, user-plus, user-round, users, x.

Shipped but named by no page (5): arrow-down, arrow-up, pencil, shield, trash.

Flow 01 (T335) added 29: arrow-left-right, ban, book-check, book-open, building, calendar-check, chevron-left, circle-plus, clipboard-list, download, gauge, graduation-cap, history, list, list-checks, lock, log-in, mail, menu, message-square, refresh-cw, scale, shield-check, stethoscope, trending-up, triangle-alert, user-check, user-plus, user-round. `alert-triangle` (a plain triangle, one path) and `triangle-alert` (the rounded triangle the alerts draw) both ship: the Coordinator's Stalled requests card names the first, the error bar and the error page the second.

**Thirteen older files (T010) are simplified redrawings, not Lucide's paths**, so do not match a glyph against them: `home` (a roof and walls, no door; the nav's Home and every "Go to Home"), `user` (the account row, a nav item), `inbox` (the Assessor's Activity inbox), `search` (Page not found; a radius of 7, Lucide's is 8), `info` (`M12 10v6`, where the info alert's mask draws Lucide's `M12 16v-4`), `settings` (spokes, not Lucide's gear), `calendar` (a 16-tall body; `calendar-check` is Lucide's 18), `users`, `book`, `file-text`, `pencil`, `trash`, and `alert-triangle` (a plain triangle; `triangle-alert` is Lucide's). The other 41, the 29 flow 01 added among them, are Lucide's own paths. Replacing the thirteen with Lucide's files is a code change, not this system's.

Add an icon by copying its Lucide SVG into `wwwroot/icons/` and giving its root `id="i"`. Never use the Bootstrap Icons font, emoji or pictures instead.
